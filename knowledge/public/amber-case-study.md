# Amber loyalty platform by Al Tayer Group

Apptunix's public Amber case study describes maintaining and optimizing Al Tayer Group's multi-brand loyalty platform for mobile and web. Amber serves fashion, lifestyle, hospitality, beauty and luxury retail brands in the UAE.

The case study specifically describes Flutter app performance work, React JS frontend enhancements and GoLang backend optimization. Services include bug fixes, interface improvements, app-store compliance updates, loyalty API integrations, database optimization and monitoring. These are statements from Apptunix's case study, not independently audited performance results.
